# Roblox Guide Site Template Astro

Astro + Cloudflare Pages Roblox guide template.

## Features

- Static Astro output
- Cloudflare Pages ready
- Minimal default public surface
- Static sitemap.xml generation
- Static robots.txt generation
- SEO-safe placeholder defaults
- Evidence-first Roblox guide workflow

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run check
```

## Cloudflare Pages

Framework preset:

```text
Astro
```

Build command:

```text
npm run build
```

Output directory:

```text
dist
```

## Launch checklist

1. Replace site name
2. Replace domain
3. Replace contact email
4. Replace homepage metadata
5. Verify sitemap.xml
6. Verify robots.txt
7. Run npm run check
8. Deploy to Cloudflare Pages
